# Guía rápida · Control de Importaciones

**Ingreso:** abre **Logística → Control Importaciones** en el menú lateral.

## 1. Buscar una importación

Al ingresar se muestran las 100 importaciones más recientes. Selecciona una opción de búsqueda, completa el criterio y pulsa **Buscar**. Puedes consultar por número de importación, anexo contable, estado, guía y otras opciones disponibles.

Usa **Anterior** y **Siguiente** para recorrer los resultados. Pulsa una fila para seleccionar la importación sobre la que trabajarás.

## 2. Registrar o modificar

1. Pulsa **Adicionar** para crear una importación. Para editar una existente, selecciónala y pulsa **Modificar**.
2. Revisa las fechas y completa el anexo contable, lugar de importación, país DUA, moneda y tipo de ítem. En los selectores filtrables puedes buscar por código o descripción.
3. Completa los documentos y datos que correspondan: Proforma, Confirmación de pedido, Orden de compra, Factura comercial, Póliza, Embarque y guía. Usa los botones de **tres puntos (…)** para abrir cada formulario. El botón **Ad** permite ingresar una factura adicional.
4. Revisa **Observaciones**. Al aceptar la Proforma se incorpora su número al texto inicial; puedes completar o editar la observación.
5. Añade los **Conceptos** y las **Condiciones de pago** que correspondan.
6. Pulsa **Guardar importación** o **Guardar cambios** para registrar la información.

Las fechas de los registros nuevos se completan con la fecha de hoy. Revisa el tipo de cambio y los importes antes de guardar. Al modificar se conservan los datos registrados.

## 3. Conceptos y condiciones de pago

- **Conceptos:** pulsa **Adicionar**, selecciona el concepto y revisa los importes, tipo de cambeio y número de proforma. Pulsa **Aceptar**.
- **Condiciones de pago:** pulsa **Adicionar**, busca y selecciona la condición y pulsa **Aceptar**. Una fila pendiente puede mostrarse como **Nueva**; la secuencia definitiva se asigna al guardar.
- Usa los iconos de cada fila para modificar o eliminar. La eliminación solicita confirmación.

**Aceptar deja los cambios pendientes. Debes guardar la importación para registrarlos.** Cancelar o Regresar descarta los cambios pendientes del formulario.

**Excepción:** el catálogo de Embarques tiene su propio botón **Guardar**. Sus cambios se registran desde ese mantenimiento.

## 4. Consultar facturas y eliminar

Para consultar las facturas asociadas, abre una importación existente y pulsa **Ver facturas**.

Para eliminar una importación, selecciónala en el listado, pulsa **Eliminar** y confirma después de revisar el número indicado. La operación está sujeta a los permisos y validaciones del sistema.

## 5. Provisionar o revertir

Selecciona una importación y pulsa **Provisionar**:

- **Registrada (R):** solicita confirmación para generar la provisión contable.
- **Provisionada (P):** el mismo botón solicita confirmación para revertir la provisión.
- **Otros estados:** no se ejecuta la operación contable.

Revisa el número de importación y la acción indicada antes de confirmar. Al finalizar, el listado se actualiza.
